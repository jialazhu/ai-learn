# 五子棋游戏模式说明

## 支持的游戏模式

五子棋AI Agent现在支持三种不同的游戏模式：

### 1. AI自主对战模式 (auto)
**命令**: `python run_demo.py --mode auto`

**特点**:
- AI同时扮演黑棋和白棋
- 完全自主思考和决策
- 使用AI深度思考引擎
- 展示完整的思考过程
- 自动进行到分出胜负

**适用场景**:
- 观看AI自我对弈学习
- 测试AI策略效果
- 演示AI思考能力

**示例输出**:
```
🧠 AI自主下棋演示
=======================================

[1] 初始化游戏 ⚙
✓ 初始化完成

┌─ 对局进行中 ──────────────────────────────┐
│ 🧠 AI思考分析:                           │
│   推荐走法: (8, 6)                     │
│   决策原因: 攻击机会#1                  │
│   置信度: ⭐⭐⭐⭐                        │
│ 第 1手: ● 黑棋 (7, 7)                 │
│ 第 2手: ○ 白棋 (7, 8)                 │
└───────────────────────────────────────────┘
```

---

### 2. 人机对战模式 (human)
**命令**: `python run_demo.py --mode human`

**特点**:
- 人类玩家执黑棋先手
- AI执白棋后手
- AI展示完整思考过程
- 实时棋盘状态显示
- 输入坐标进行走子

**适用场景**:
- 与AI对战挑战
- 学习五子棋策略
- 体验AI思考过程

**操作方式**:
- 输入格式：`行,列`（如：`7,7`）
- 坐标范围：0-14
- 输入 `q` 退出游戏

**示例交互**:
```

👉 请输入: 8,8
✓ 人类(●) 已落子: (8, 8)

┌─ 第5轮：AI(○) 思考中 ────────────────────┐
│ 🤖 AI正在分析局面并计算最佳走法...        │
└───────────────────────────────────────────┘
```

---

### 3. 玩家对战模式 (pvp) 🆕
**命令**: `python run_demo.py --mode pvp`

**特点**:
- 两个人类玩家对战
- 玩家1执黑棋，玩家2执白棋
- 可选AI走子建议功能
- 支持用户统计记录
- 实时棋盘显示

**适用场景**:
- 双人对战娱乐
- 五子棋练习
- 比赛和对弈

**操作方式**:
- 输入格式：`行,列`（如：`7,7`）
- 输入 `hint` 获取AI建议
- 输入 `quit` 退出游戏

## 启动方式

### 方法1: 直接运行主程序
```bash
# AI自主对战
python run_demo.py --mode auto

# 人机对战
python run_demo.py --mode human

# 玩家对战
python run_demo.py --mode pvp
```

### 方法2: 使用演示脚本
```bash
# 用户系统演示
python demo_user_system.py

# PvP模式专用演示
python demo_pvp.py

# AI思考功能演示
python demo_ai_thinking.py
```

## 游戏规则

### 基本规则
1. **棋盘大小**: 15x15标准五子棋棋盘
2. **坐标范围**: 0-14（横纵坐标）
3. **先行权**: 黑棋先行，白棋后行
4. **获胜条件**: 任意方向（横、竖、斜）连成5个同色棋子
5. **平局**: 棋盘下满无人获胜

### 输入格式
- **标准坐标**: `行,列`（如：`7,7`）
- **空格分隔**: `行 列`（如：`7 7`）
- **示例**: `7,7`、`8 9`、`10,12`

### 特殊命令
- `hint` / `建议`: 获取AI走子建议（仅PvP模式）
- `quit` / `exit` / `q`: 退出当前游戏

## 用户系统集成

所有游戏模式都支持用户系统集成：

### 登录用户优势
- ✅ **游戏统计**: 自动记录游戏场次、胜负、胜率
- ✅ **进度保存**: 游戏进度关联到用户账号
- ✅ **个性化体验**: 用户专属的游戏历史

### 用户操作示例
```bash
# 通过Agent对话管理用户
python run_demo.py --mode human

# 对话示例：
用户: "帮我注册账号"
Agent: "请提供用户名、密码、邮箱"

用户: "我要登录"
Agent: "请提供用户名和密码"

用户: "查看我的游戏统计"
Agent: [显示用户统计信息]
```

## AI思考引擎

在涉及AI的游戏模式中，AI会展示深度思考过程：

### 思考阶段
1. **局面分析** - 评估当前游戏阶段和棋盘状态
2. **威胁检测** - 识别对手威胁和自身机会
3. **机会寻找** - 发现必胜走法和攻击机会
4. **策略规划** - 制定最优策略
5. **最终决策** - 选择最佳走法并给出置信度
