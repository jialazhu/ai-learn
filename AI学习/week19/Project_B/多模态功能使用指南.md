# 多模态风控系统使用指南

## 📖 概述

Project_B的多模态风控系统在原有LightGBM预测基础上，增加了图像分析和智能解释功能，支持身份证验证、票据检查等多种风控场景。

## 🚀 快速开始

### 1. 环境准备

#### 1.1 安装Python依赖
```bash
# 进入Project_B目录
cd AI学习/week19/Project_B

# 安装依赖包
pip install -r requirements.txt
```

#### 1.2 安装Ollama
```bash
# macOS
brew install ollama

# Linux
curl -fsSL https://ollama.ai/install.sh | sh

# Windows
# 从 https://ollama.com/download 下载安装
```

#### 1.3 启动Ollama服务
```bash
ollama serve
```

#### 1.4 拉取必要模型
```bash
# 文本模型（必需）
ollama pull qwen3:4b

# 多模态模型（图像分析必需）
ollama pull qwen3-vl:4b

# 检查已安装模型
ollama list
```

#### 1.5 可选：安装Tesseract OCR
```bash
# Ubuntu/Debian
sudo apt-get install tesseract-ocr tesseract-ocr-chi-sim

# macOS
brew install tesseract tesseract-lang

# Windows
# 从 https://github.com/UB-Mannheim/tesseract/wiki 下载安装
```

### 2. 启动服务

#### 2.1 使用启动脚本（推荐）
```bash
# 自动检查环境并启动
python start_multimodal_api.py
```

#### 2.2 手动启动
```bash
# 直接启动多模态API
python src/api/app_multimodal.py
```

#### 2.3 验证服务
- API服务地址：http://localhost:8001
- API文档：http://localhost:8001/docs
- 健康检查：http://localhost:8001/health

### 2. 多模态预测接口（核心功能）

**接口**：`POST /predict/multimodal`

**用途**：结合特征和图像的综合分析

**示例**：
```bash
curl -X POST "http://localhost:8001/predict/multimodal" \
  -F "features='{\"Time\": 0.0, \"Amount\": 149.62, \"V1\": -1.3598, ...}'" \
  -F "images=@id_card.jpg" \
  -F "image_types=id_card"
```

**Python示例**：
```python
import requests

# 特征数据
features = {
    "Time": 0.0,
    "Amount": 149.62,
    "V1": -1.3598,
    # ... 其他28个特征
}

# 图像文件
files = {
    'features': (None, json.dumps(features), 'application/json'),
    'images': ('id_card.jpg', open('id_card.jpg', 'rb'), 'image/jpeg'),
    'image_types': (None, 'id_card'),
    'explain': (None, 'true'),
    'use_llm': (None, 'true')
}

# 发送请求
response = requests.post('http://localhost:8001/predict/multimodal', files=files)
result = response.json()
print(result)
```

### 3. 纯图像分析接口

**接口**：`POST /analyze/image`

**用途**：仅分析图像，不涉及预测

**示例**：
```bash
curl -X POST "http://localhost:8001/analyze/image" \
  -F "image=@receipt.jpg" \
  -F "image_type=receipt" \
  -F "features='{\"Amount\": 1000.0}'"
```

### 4. 批量预测接口

**接口**：`POST /predict/batch`

**用途**：批量处理多个交易样本

**示例**：
```bash
curl -X POST "http://localhost:8001/predict/batch" \
  -H "Content-Type: application/json" \
  -d '{
    "batch_id": "batch_001",
    "samples": [
      {"Time": 0.0, "Amount": 100.0, "V1": -1.2, ...},
      {"Time": 1.0, "Amount": 200.0, "V1": 0.5, ...}
    ],
    "explain": true,
    "use_llm": false
  }'
```

## 🖼️ 支持的图像类型

### 1. 身份证分析 (id_card)
- **功能**：检测身份证真实性、人脸识别
- **支持**：身份证正面、身份证+自拍比对
- **输出**：真实性评估、人脸匹配度、风险等级

### 2. 票据分析 (receipt)
- **功能**：验证票据真伪、金额匹配
- **支持**：发票、收据、银行票据
- **输出**：票据验证结果、金额一致性检查

### 3. 自拍分析 (selfie)
- **功能**：活体检测、质量评估
- **支持**：人脸照片、活体视频帧
- **输出**：人脸质量、活体检测结果

### 4. 文档分析 (document)
- **功能**：通用文档OCR和真实性检查
- **支持**：合同、申请表等文档
- **输出**：文字提取、文档完整性检查

### 2. 风险等级说明
- **VERY_LOW** (0-0.3)：极低风险，建议通过
- **LOW** (0.3-0.5)：低风险，可正常处理
- **MEDIUM** (0.5-0.7)：中等风险，建议人工复核
- **HIGH** (0.7-0.8)：高风险，建议拦截
- **CRITICAL** (>0.8)：极高风险，必须拦截

## 🎯 实际应用场景

### 1. 身份验证场景
```python
# 用户注册或开户时的身份验证
features = extract_user_features(user_data)
id_card_image = upload_file("id_card.jpg")
selfie_image = upload_file("selfie.jpg")

result = predict_multimodal(
    features=features,
    images=[id_card_image, selfie_image],
    image_types=["id_card", "selfie"]
)

if result.overall_risk.level in ["HIGH", "CRITICAL"]:
    reject_user_registration()
else:
    proceed_with_registration()
```

### 2. 交易风控场景
```python
# 大额交易或多因素验证
transaction_data = get_transaction_features()
receipt_image = upload_file("receipt.jpg")

result = predict_multimodal(
    features=transaction_data,
    images=[receipt_image],
    image_types=["receipt"]
)

# 根据综合风险等级决定处理方式
if result.overall_risk.level == "CRITICAL":
    block_transaction()
elif result.overall_risk.level == "HIGH":
    require_additional_verification()
else:
    approve_transaction()
```

### 3. 票据审核场景
```python
# 财务票据真实性验证
transaction_amount = 10000.00
invoice_image = upload_file("invoice.jpg")

result = analyze_image_only(
    image=invoice_image,
    image_type="receipt",
    features={"Amount": transaction_amount}
)

if result.risk_level == "HIGH":
    flag_for_manual_review()
elif result.additional_info["amount_match"]["match"]:
    approve_invoice()
else:
    request_clarification()
```

### 1. 常见问题

#### 图像处理失败
- 检查图像格式是否支持
- 确认图像文件大小不超过10MB
- 验证图像文件是否损坏

